# Besta automática
Secundária (`crossbow`): uma **besta de mão** pequena, estilo pistola. **Segure** o botão secundário: dispara virotes a cada 0,12 s (~8/s) com **4 de dano** cada, anda devagar (2,4 m/s) enquanto atira; esquiva e ataque cancelam. Mira no alvo travado ou à frente, com leve dispersão. Os acertos carregam o medidor da arte.
Código: `player/states/crossbow.gd` (estado), `combat/bolt.gd` (virote), `Player.fire_bolt()`.
